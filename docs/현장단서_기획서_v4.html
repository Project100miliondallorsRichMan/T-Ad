설치 사진을 기술의 증거로 바꾸는 AI 홍보 도구

AI 스마트워크톤 트랙 A · 티링크 과제 · 기획서 v4 · 2026-11-20

한 줄 소개

설치 현장 사진을 티링크 기술의 증거로 바꿔, 회사가 승인한 제품 근거로만 업종별 홍보 콘텐츠를 만들고 근거 없는 수치는 코드로 걸러 내는 마케팅 도구

대상 사용자

  • 티링크 설치 기사·영업 담당자: 현장 사진 업로드, 태그 확인
  • 마케팅 담당자: 콘텐츠 검수·게시
  • 확장 단계: "우리 사무실에도 설치될까?"가 궁금한 잠재고객

해결하려는 문제

  • 티링크의 강점(기존 전화기·회선 교체 불필요, 통신사 무관, 좁은 단자함에도 설치)은 눈에 보이지 않는 기술이다. 현장 사진은 단자함·케이블뿐이라 구매자가 "우리에게 무슨 의미인지" 읽기 어렵다.
  • 홈페이지 설치 사례 갤러리(5개 업종 12건)는 대부분 업종 태그와 마스킹된 고객명만 있고, 어떤 문제를 어떤 기술로 풀었는지 설명이 빠져 있다.
  • 학교는 교권 보호·S2B 구매, 콜센터는 기록·경영 리포트에 반응하는 등 구매자마다 메시지가 달라, 같은 사진도 업종마다 글을 다시 써야 한다.
  • 생성형 AI로 쓰면 '민원 30% 감소' 같은 근거 없는 수치가 섞일 수 있어, 표시·광고 리스크 때문에 그대로 게시하기 어렵다.

→
근거 매칭
→
생성
→
직원 검수
  1. 제품 지식 베이스: 홈페이지·특허 자료를 '기능 / 고객 이점 / 근거(출처) / 어울리는 업종'으로 정리한 JSON. 회사가 증빙할 수 있는 문구만 등록하고 타사 비교 문구는 제외한다.
  2. 사진 분석(반자동): 비전 AI가 설치 형태(스탠드형·랙거치형·미러링 스위치허브)와 문제 태그(예: 단자함 공간 부족) 후보를 제안하고, 직원이 선택·수정한다. 사진에 보이는 것만 다루고 품질 평가는 하지 않는다.
  3. 근거 매칭 + 업종별 생성: 확정된 태그를 지식 베이스 근거와 연결해 '문제 → 해결 → 결과' 구조로 생성한다. 같은 사진도 업종을 바꾸면 메시지가 구매자에 맞게 바뀐다.
  4. 코드 팩트체크: 생성된 글에서 수치를 정규식으로 추출·정규화해 지식 베이스 수치와 대조한다. 근거 없는 수치와 금지 표현(최고·1위 등)은 빨간색 '확인 필요'로 표시하고, 일치한 수치는 출처를 표시한다. AI가 AI를 검사하지 않고 규칙으로 검증한다. 게시 승인은 항상 직원이 한다.

주요 기능

핵심 기능 1사진 업로드 + 업종·제품 선택 → 설치 형태·문제 태그 제안 → 직원 확인·수정
핵심 기능 2블로그 설치 후기 + 카드뉴스 5장 문구(장별 사용 사진 지정) 생성, 업종 변경 시 메시지 재생성
핵심 기능 3코드 팩트체크가 적용된 검수 화면(수정 후 복사)
MVP 범위제품 지식 베이스 JSON과 대표 설치 사례 1건 탑재. 웹 화면 1개에서 업로드 → 태그 확인 → 생성 → 검증 → 복사까지 동작. 업로드 전 IP 스티커·내선번호·패치패널 라벨·얼굴·간판 노출 확인 체크 필수
제외·확장OCR 자동 모자이크, 카드뉴스 이미지 렌더링, 영업 문자·홈페이지 사례 채널, 사례 DB, 잠재고객용 "우리 사무실에도 될까?" 진단 페이지(홈페이지의 "현장 사진 보내주세요" 안내를 자동화)
한계숫자 없는 주장은 금지어 외에는 검출하지 못해 직원 최종 검수가 필요하다. 범용 비전 모델의 장비 인식 정확도는 검증되지 않아 반자동 방식으로 시작한다.
