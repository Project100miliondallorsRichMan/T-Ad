# 팩트체크 오탐·미탐 기록 (#7)

> **요약.** 실제 Gemini 생성 글 3건(블로그 + 카드뉴스 5장씩)에서 수치 17개를 검사했고, **근거 없는 수치 0건, 금지 표현 0건**이 나왔다. 다만 사람이 읽어 보니 **숫자 없는 근거 없는 주장 2건**이 있었고, 이는 코드로 잡을 수 없다. 그래서 발표에서는 "근거 없는 **수치** 0건"이라고 말하고, 나머지는 직원 검수 단계가 맡는다고 설명한다.

## 방법

1. **표현 바꿔 넣기**: 같은 사실을 생성형 AI가 쓸 법한 여러 표기(`30개국`, `서른 개국`, `150여 곳`, `₩1,500,000`, `40프로`, `100퍼센트` 등 80개)로 바꿔 `factcheck.check`에 넣고 결과를 확인했다.
2. **모의 생성 글 3건**: 업종 3개(공공·복지 / 교육(학교) / 콜센터·기업)마다, 앱 출력 형식(블로그 + 카드뉴스 5장)대로 글을 썼다. 근거가 있는 수치와 함께, AI가 자주 지어내는 근거 없는 수치·금지 표현을 글마다 5개씩 넣었다. → [`docs/factcheck_samples/mock_*.json`](factcheck_samples/)
3. 기존 규칙(`main`)과 보강한 규칙을 같은 글에 돌려 비교했다.

## 결과: 모의 글 3건

넣어 둔 문제 15개(근거 없는 수치 9개 + 금지 표현 6개)를 기준으로 셌다.

| 글 | 넣어 둔 문제 | 기존 규칙 검출 | 보강 후 검출 | 기존 오탐 | 보강 후 오탐 |
|---|---|---|---|---|---|
| mock_1 공공·복지 | 5 | 3 | **5** | 0 | 0 |
| mock_2 교육(학교) | 5 | 4 | **5** | 1 | 0 |
| mock_3 콜센터·기업 | 5 | 1 | **5** | 1 | 0 |
| **합계** | **15** | **8** | **15** | **2** | **0** |

> 주의: 규칙을 보강한 근거가 이 모의 글과 같은 표현들이라, 보강 후 15/15는 실제 글에서의 성능을 뜻하지 않는다. 실제 생성 글로 다시 재야 한다.

### 미탐 (틀렸는데 통과) — 기존 규칙

| 원문 | 왜 놓쳤나 | 조치 |
|---|---|---|
| `하루 만에 설치` | 한글 수(하루) 미지원 | 하루·이틀·사흘·나흘 → `일` |
| `두 배 높아졌습니다` | 한글 수(두) 미지원 | 한·두·세…열·스무·서른·마흔·쉰 + 배/개/명/곳/시간/회선/언어 |
| `200회선`, `50회선` | `회선` 단위 없음 | `회선` 추가 |
| `40프로 향상` | `프로` 단위 없음 | `프로`=`%` (단, `프로그램`·`프로젝트` 제외) |
| `100퍼센트 안전` | `100%` 문자열만 금지 | 정규화 값이 100%면 표기와 관계없이 금지 표현 |
| `전국 1등`, `No.1`, `독보적` | 금지어 목록에 없음 | `1등`, `No.1`, `넘버원`, `최상`, `독보적`, `압도적`, `단 하나` 추가 |

### 오탐 (맞는데 '확인 필요' 또는 '금지 표현') — 기존 규칙

| 원문 | 왜 걸렸나 | 조치 |
|---|---|---|
| `150여 곳의 학교` (근거: 150여 개 학교) | `곳`과 `개`를 다른 단위로 봄 | `곳`=`개`로 정규화 |
| `30개국 이상` (근거: 30개국 이상) | `30개`까지만 잘라 읽음 | `개국` 단위 추가(main #4와 같은 방식). 나라 수 `30개국`과 언어 수 `30개 언어`는 다른 값으로 본다 |
| `최고경영자 보고용 리포트` | 낱말 속 `최고` | 예외 낱말 목록(`BANNED_EXCEPTIONS`): 최고경영자, 최고책임자, 보장성, 1등급 등 |
| `₩1,500,000` (근거: 150만 원) | 기존엔 아예 검사 안 함(미탐 쪽) | `₩` 앞 표기 지원 |

## 남은 한계 (일부러 그대로 둠)

- **계산해서 나온 수치**: `2006년 설립 이후 20년`은 사실일 수 있지만 근거에 `20년`이 없어 '확인 필요'로 뜬다. 직원이 확인하도록 그대로 둔다.
- **단위 없는 주장**: `가장 쉬운`, `확실하게`, `반드시 해결`, `반나절이면` 같은 표현은 잡지 못한다. `가장`을 금지어로 넣으면 오탐이 너무 많아진다. 게시 전 직원 검수가 필요하다.
- **섞어 쓴 표기**: `1백50만 원`은 `50만 원`만 잘라 읽는다. 그래도 '확인 필요'로 뜨므로 놓치지는 않는다.
- **`보장`**: `개인정보 보호를 보장` 같은 문장도 금지 표현으로 뜬다. 단정 표현이라 일부러 남겼다.

## 실제 생성 글 3건 (Gemini)

- 모델 `gemini-3.8-flash`. `gemini-2.5-flash`는 신규 사용자에게 제공되지 않는다는 404가 나서 바꿨다(#2 참고).
- 시나리오: 시연 사진 3장(스탠드형 / 미러링 스위치허브 / 랙거치형)에 업종 3개를 붙였다. → [`docs/factcheck_samples/real_*.json`](factcheck_samples/)
- 실행: `python tests/factcheck_eval.py --generate`

| 글 | 업종 · 제품 | 검사한 수치 | 근거 있음 | 확인 필요 | 금지 표현 | 사람 판정: 숫자 없는 근거 없는 주장 |
|---|---|---|---|---|---|---|
| real_1 | 공공·복지 · AI 녹취 | 5 | 5 | 0 | 0 | 1 |
| real_2 | 교육(학교) · 학교용 녹취 | 8 | 8 | 0 | 0 | 0 |
| real_3 | 콜센터·기업 · AI 녹취 | 4 | 4 | 0 | 0 | 1 |
| **합계** | | **17** | **17** | **0** | **0** | **2** |

**정탐 확인**: '근거 있음' 17개(99%, 2023년, 제10-2599434호, 2006년, 150만 원, 150여 개, 두 곳)는 모두 지식 베이스나 직원이 확인한 사진 설명과 하나하나 대조했고, 전부 맞다. 오탐은 없었다.

**미탐: 숫자 없는 근거 없는 주장 (코드로 잡을 수 없음)**

| 글 | 문장 | 왜 문제인가 |
|---|---|---|
| real_1 | "ARM CPU 기반 휴대용 녹취서버 특허(제10-2599434호) 기술이 적용된 **스탠드형 본체로 해결**했습니다" (카드 3도 비슷함) | 특허 번호는 근거에 있지만, 그 특허가 이 스탠드형 장비에 쓰였다는 근거는 없다. 맞는 사실 두 개를 잘못 이어 붙였다. |
| real_3 | "같은 랙에 나란히 배치되어 **추가 공간 차지 없이**" | 1U 장비도 랙 공간을 쓴다. 사진 설명을 넘어선 과장이다. |

**그 밖의 관찰**
- AI가 성공률 99%에 "(회사 발표 수치)"를 스스로 붙였다. 지식 베이스의 note를 따른 것이다.
- 금지어는 3건 모두 0건이었다. 생성 프롬프트의 규칙 2가 잘 지켜진다.
- 카드뉴스 `photo` 칸이 비어 있거나 "사진 1"을 쓰라고 했는데 "사진 사진 1"처럼 나온다. 프롬프트·앱 담당(#5, #6, #8)에 알린다.

**결론**: 코드 팩트체크는 근거 없는 **수치**와 **금지 표현**을 막는다. 사실 둘을 잘못 잇는 것 같은 의미 수준의 과장은 막지 못하므로, 게시 전 직원 검수가 꼭 필요하다(README '한계'와 같은 내용).
