# 예상 질문과 30초 답변

[ ] 칸은 측정·테스트가 끝나면 채운다. 채우지 못한 숫자는 말하지 않는다.

## 1. 그래도 AI가 틀린 말을 하면 어떻게 하나요?

세 겹으로 막습니다. 첫째, AI에게는 회사가 승인한 근거 목록만 주고 그 밖의 수치는 쓰지 말라고 지시합니다. 둘째, 지시를 어겨도 코드가 생성된 글의 수치를 모두 뽑아 근거와 대조하고, 없는 수치와 '최고·1위' 같은 표현을 빨간색으로 표시합니다. 셋째, 게시 버튼은 항상 직원이 누릅니다. 숫자가 없는 주장은 코드로 못 잡는다는 한계도 화면과 발표에서 밝히고 있습니다.

## 2. 그냥 ChatGPT에 사진을 넣고 써 달라고 하면 되지 않나요?

글 한 편은 그렇게 쓸 수 있습니다. 하지만 매번 제품 자료를 붙여 넣고, 업종마다 다시 요청하고, 나온 수치를 사람이 하나하나 검수해야 합니다. 현장단서는 근거를 지식 베이스에 한 번만 정리해 두고, 업종 선택만 바꾸면 메시지가 바뀌고, 검수는 코드가 먼저 합니다. 차이는 '글을 써 주는 것'이 아니라 '그대로 올려도 되는 글인지 확인해 주는 것'입니다.

## 3. 사진 속 고객사 정보가 새어 나가지 않나요?

단자함·랙 사진에는 IP 스티커, 내선번호, 간판이 찍힐 수 있습니다. 그래서 업로드 전에 노출 확인 체크를 해야만 업로드가 열리고, 사진 분석 프롬프트도 IP·번호·간판 글자를 옮겨 적지 않도록 막았습니다. 생성 단계에서는 고객사 이름과 상세 지역을 쓰지 않습니다. 다음 단계로 OCR 자동 모자이크와 사진별 공개 동의 상태를 계획하고 있습니다.

## 4. 운영 비용은 얼마나 드나요?

화면은 Streamlit Community Cloud에 무료로 배포했고, 비용은 Gemini API 사용량뿐입니다. 정확한 금액은 사용량과 요금제에 따라 달라서 대회에서는 측정하지 않았습니다. 다만 실제 고객 사진을 다룰 때는 입력 데이터가 학습에 쓰이지 않는 유료 등급을 쓰는 것이 맞다고 보고, 이를 한계로 밝혔습니다.

## 5. 시간이 줄어든다는 숫자의 근거는 무엇인가요?

추정치가 아니라 팀이 직접 잰 값입니다. 같은 사진으로 팀원 한 명은 직접 블로그와 카드뉴스 문구를 쓰고, 다른 한 명은 현장단서로 만들어 시간을 쟀습니다. 결과는 사람 [n분], 현장단서 [n분]이고 [n회] 측정했습니다. 측정 횟수가 적어서 연간 절감액 같은 확대 계산은 하지 않았습니다. 측정 방법은 docs/measurement.md에 있습니다.
