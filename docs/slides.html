현장단서

설치 사진 한 장을 기술의 증거로.
근거 있는 홍보 콘텐츠만 만들고, 근거 없는 수치는 코드가 잡아냅니다.
사진 1건 홍보물: 사람 [n분] → 현장단서 [n분] · 팀 T-Ad
1
문제

기술은 강한데, 보여 줄 것은 단자함 사진뿐입니다

  • 티링크의 강점은 눈에 보이지 않습니다. 기존 전화기·회선 교체 불필요, 통신사 무관, 좁은 단자함에도 설치.
  • 현장 사진은 회색 박스와 케이블. 설치 사례 갤러리는 대부분 업종 태그와 가려진 고객명만 있고, 어떤 문제를 어떤 기술로 풀었는지 설명이 없습니다.
  • 학교는 교권 보호, 콜센터는 기록·경영 리포트, 건설 현장은 통역·작업보고. 같은 사진도 구매자마다 다시 써야 합니다.
  • 생성형 AI에 맡기면 '민원 30% 감소' 같은 근거 없는 수치가 섞여 그대로 올릴 수 없습니다.
2
지금 방식 (As-Is)

사진 1건을 홍보물로 만들려면 사람이 전부 합니다

사진 고르기현장에서 받은 사진
→
사진 해석무슨 장비, 어떤 형태?
→
자료 찾기홈페이지·특허에서 근거
→
업종별 작성블로그·카드뉴스를 업종마다
→
과장 검수수치·표현 하나하나

시간이 새는 곳: 같은 근거를 매번 다시 찾기, 업종마다 다시 쓰기, 사람 눈으로 수치 검수

팀 실측: 사진 1건당 [n분] (docs/measurement.md)

3
솔루션 (To-Be)

사진 → 분석 → 근거 매칭 → 생성 → 검수, 한 흐름

사진 업로드노출 확인 체크 필수
→
사진 분석AI가 설치 형태·문제 태그 제안
→
직원 확인태그·설명 수정
→
업종별 생성승인된 근거만 사용
→
코드 팩트체크근거 없는 수치 빨간색

AI는 "무엇이 보이는가"만 제안하고,
"무엇을 주장해도 되는가"는 회사가 승인한 지식 베이스가 정합니다.

게시 승인은 항상 직원이 합니다.

5
어떻게 만들었나

AI가 AI를 검사하지 않습니다. 규칙으로 검증합니다

구성

  • 화면: Python + Streamlit
  • AI: Gemini (사진 분석·글 생성)
  • 근거: 제품 지식 베이스 JSON (항목마다 출처)
  • 프롬프트 규칙: 보이는 것만 / 근거 목록 밖 수치 금지 / 최상급 표현 금지 / IP·번호 옮겨 적기 금지

코드 팩트체크 예시

녹취 성공률 99%근거, 최대 3000석근거까지 구축.

도입 후 민원 30%확인 필요 감소, 업계 최고금지 표현 수준.

수치를 정규식으로 뽑아 '3,000석=3000석', '150만 원=1,500,000원'으로 맞춘 뒤 지식 베이스와 대조합니다.

7
확산 가능성

지식 베이스 파일 하나만 바꾸면 됩니다

티링크 안에서

  • AI 녹취 → 학교용 녹취 → 티링크 온까지 제품만 선택
  • 같은 사진을 공공·교육·콜센터·금융·의료·건설 메시지로

다른 회사에서

  • 설치·시공 사진이 쌓이는 B2B 기업
  • 예: 보안 장비 설치, 냉난방·공조 시공, 태양광 시공
  • 필요한 것: 제품 근거 JSON, 업종 목록
8
