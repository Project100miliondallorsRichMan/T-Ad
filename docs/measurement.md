# 작성 시간 측정 (사람 vs 현장단서)

발표와 README의 효과 수치는 이 표에 기록한 값만 쓴다. 추정치는 쓰지 않는다.

## 측정 방법

1. 같은 설치 사진 세트(2~3장)와 같은 업종·제품을 정한다.
2. **사람:** 팀원 1명이 홈페이지 제품 자료를 보며 블로그 설치 후기 1편과 카드뉴스 5장 문구를 직접 쓴다. 자료 찾기부터 과장 표현 검수까지 포함해 타이머로 잰다. AI 도구는 쓰지 않는다.
3. **현장단서:** 다른 팀원이 같은 사진으로 업로드부터 검수 완료(확인 필요 0건)까지 잰다.
4. 사람이 쓴 글도 `factcheck.py`로 검사해 근거 없는 수치 개수를 같이 적는다.
5. 가능하면 사진 세트 2개로 반복한다.
